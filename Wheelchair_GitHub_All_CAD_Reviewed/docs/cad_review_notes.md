# CAD 자료 검토 기록

이 폴더는 완성된 CAD 모델을 역설계한 결과물이 아니라, 남아 있는 원본 파일을 정리한 기록입니다.

## 원본 구성

- SolidWorks 부품(.SLDPRT): 18개
- SolidWorks 조립(.SLDASM): 2개
- AutoCAD 도면(.dwg): 서로 다른 2개
- SHA-256이 일치하는 `무한궤도 바퀴 (1).dwg`와 `무한궤도 바퀴.dwg` 가운데 한 파일만 보관

## 설계 수정과 관련해 판단할 수 있는 것

- `하부 프레임 예시1` / `하부 프레임 파트1`: 서로 다른 저장 파일로, 하부 프레임을 검토한 자료가 둘 이상 존재함.
- `판베어링` / `판베어링25`: 서로 다른 저장 파일로, 연결부 모델이 둘 이상 존재함.
- `25mm`, `30mm`, `35mm`, `40mm`, `360mm` 리벳: 파일명과 내용이 서로 다름. **규격별 부품일 가능성이 있어 순서대로 개량한 버전으로 분류하지 않음.** 실제 길이는 CAD 확인 전까지 미확정.
- `시저 프레임 파트1` / `파트2`: 이름이 다른 부품 두 개. 버전 1과 버전 2를 뜻한다고 단정할 수 없음.
- `어셈블리1` / `컨버전스`: 이름이 다른 조립 파일 두 개. 동일 제품의 수정 전후인지, 별도 조립 단위인지는 미확정.
- 무한궤도 바퀴와 측면 도면: 두 종류의 서로 다른 2D 도면이 보관됨. 바퀴 설계 방식의 변경 시점은 알 수 없음.

## 실제 제작 경험과 기록 범위

CAD와 SolidWorks로 설계한 내용을 프로파일 절단과 조립에 적용했고, 바퀴의 계단 접촉 각도 및 프레임 간섭 문제 때문에 반복 수정·시험을 진행했다는 내용은 프로젝트 수행 경험에 근거합니다. 정확한 수정 횟수, 날짜, 각 버전의 채택 여부, 전후 치수 차이, 주행 성능 수치는 확인할 수 없어 적지 않았습니다.

## 파일을 여는 방법

- `.SLDPRT`와 `.SLDASM`은 SolidWorks에서 열 수 있습니다. 조립 참조가 깨지면 부품 파일 경로를 다시 지정해야 합니다.
- `.dwg`는 AutoCAD 등 DWG 지원 프로그램에서 확인할 수 있습니다.
- `images/`에는 DWG에 원래 포함된 작은 미리보기만 추출했습니다. 이미지가 곧 전체 CAD 도면은 아닙니다.
