# CAD 설계 검토 메모

2021년 휠체어 프로젝트 당시 이메일에 남아 있던 CAD 파일을 정리한 기록입니다.

## 남아 있는 자료

- SolidWorks 부품 파일(`.SLDPRT`) 18개, 조립 파일(`.SLDASM`) 2개
- AutoCAD 2D 도면(`.dwg`) 2개
- `무한궤도 바퀴 (1).dwg`와 `무한궤도 바퀴.dwg`는 내용이 같아 하나만 보관

## 파일 간 차이

| 구분 | 확인된 내용 | 확인되지 않은 내용 |
| --- | --- | --- |
| 하부 프레임 | `예시1`, `파트1` 두 개의 별도 부품 파일 | 제작 순서와 최종 채택본 |
| 판베어링 | `판베어링`, `판베어링25` 별도 파일 | 실제 적용 위치·시점 |
| 리벳 | 길이로 보이는 숫자가 다른 파일 5개 | 이름에 적힌 수치가 실제 측정 치수인지 여부 |
| 시저 프레임 | `파트1`, `파트2` 부품 파일 | 서로 다른 부품인지 수정본인지 여부 |
| 조립 | `어셈블리1`, `컨버전스` 조립 파일 | 두 조립 파일의 선후 관계와 참조 파일 완전성 |
| 2D 도면 | 무한궤도 바퀴, 측면 배치 도면 | 최종 제작품에 반영된 정도 |

실제 제작 과정에서는 계단 접촉 각도와 프레임 간섭을 확인하며 수정·조립·시험을 반복했습니다. 다만 CAD 파일의 생성 시점과 정확한 변경 전후 치수, 채택 이력이 충분히 남아 있지 않아 별도의 버전 순서를 붙이지 않았습니다.

원본 전체 목록은 [file_inventory.md](file_inventory.md)에 정리했습니다.
