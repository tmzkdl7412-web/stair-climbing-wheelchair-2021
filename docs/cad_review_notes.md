# CAD 자료 검토 기록

2021년 계단 주행 휠체어 프로젝트에서 이메일에 남아 있던 CAD 원본을 정리하면서 확인한 내용입니다.

## 파일 구성

- SolidWorks 부품(.SLDPRT): 18개
- SolidWorks 조립(.SLDASM): 2개
- AutoCAD 도면(.dwg): 중복을 제외한 2개
- `무한궤도 바퀴 (1).dwg`와 `무한궤도 바퀴.dwg`는 SHA-256이 동일하여 하나만 보관했습니다.

## 구분한 설계 자료

- **바퀴:** `앞바퀴370`, `뒷바퀴 350`, `롤러`, `축`
- **프레임:** `상부 프레임 파트1`, `하부 프레임 예시1`, `하부 프레임 파트1`, `시저 프레임 파트1·2`
- **연결 및 작동부:** `판베어링`, `판베어링25`, `실린더 원통`, `실린더 스트로크`, 길이별 이름의 리벳 모델
- **조립:** `어셈블리1`, `컨버전스`
- **2D:** 무한궤도 바퀴 및 측면 배치 도면

이름과 내용이 다른 파일이 여러 개 있지만, 수정 순서를 입증할 날짜별 기록은 없습니다. 서로 다른 파일이라는 사실과 실제로 어느 순서로 바꿨는지는 구분했습니다. 특히 리벳 파일은 규격별 부품일 수 있습니다.

## 당시 작업과 확인되지 않은 부분

CAD로 바퀴·프레임을 설계하고 프로파일 절단, 조립, 주행 시험에 참여했습니다. 실제 시험에서 계단 접촉 각도와 프레임 간섭을 확인하고 수정·재시험을 반복했습니다.

현재 자료만으로는 각 모델의 채택 여부, 수정 횟수, 정확한 변경 전후 치수, 적재하중과 주행 속도를 검증할 수 없습니다. SolidWorks 조립 파일의 외부 참조가 모두 남아 있는지도 확인되지 않았습니다. 따라서 별도 성능 수치나 시간순 버전 이력을 만들지 않았습니다.
